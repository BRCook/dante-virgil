Virgil @VERSION@, for installing without the network (@ARCH@)
===============================================

This bundle holds Virgil's Debian package. To install or upgrade, copy this folder to the device, then:

  sudo ./install.sh

Upgrading keeps the Clock Box's config, Virgil ID and certificate.

To remove Virgil later (keeping its config and logs):    sudo apt remove dante-virgil
To remove it entirely (config, logs and the virgil user):   sudo apt purge dante-virgil
